Mixtape Player

Embeddable audio player for full playlists, compact embeds, and single-track drops.

A standalone web component with local files, remote audio, waveform rendering, and preset layouts. Built to drop into real pages without bringing in a framework or a build step.

Full Variant

Editorial player with tracklist

Best for album pages, broadcasts, and mixes where the playlist is part of the experience.

Snippet

<script
  src="https://your-domain.com/dist/mixtape-player.min.js"
  data-mixtape-widget
  data-variant="full"
  data-config='{"title":"Northbound Signals","artist":"Mira Vale","cover":"https://your-domain.com/assets/northbound-signals-cover.svg","tracks":[{"title":"Signal Bloom","src":"/audio/signal-bloom.mp3"},{"title":"Night Ferry","src":"https://example.com/audio/night-ferry.ogg"}]}'
></script>

Compact Variant

Smaller footprint for embeds

A lighter card for article bodies, side modules, and tighter layouts.

Snippet

<script
  src="https://your-domain.com/dist/mixtape-player.min.js"
  data-mixtape-widget
  data-variant="compact"
  data-show-volume="false"
  data-config='{"title":"Night Ferry","artist":"Mira Vale","tracks":[{"title":"Night Ferry","src":"/audio/night-ferry.mp3"}]}'
></script>

Minimal Variant

Single-track and lightweight

Use it when the player should feel like a compact product module, not a full music surface.

Snippet

<script
  src="https://your-domain.com/dist/mixtape-player.min.js"
  data-mixtape-widget
  data-variant="minimal"
  data-config='{"title":"Terminal Glow","artist":"Mira Vale","tracks":[{"title":"Terminal Glow","src":"/audio/terminal-glow.mp3"}]}'
></script>

Classic Mount

Programmatic setup with JavaScript

Use the custom element directly when you want to manage configuration inside your own scripts.

Snippet

<script src="dist/mixtape-player.min.js"></script>
<mixtape-player id="player"></mixtape-player>
<script>
  const player = document.querySelector("#player");
  player.load({
    variant: "full",
    title: "Northbound Signals",
    artist: "Mira Vale",
    tracks: [{ title: "Signal Bloom", src: "/audio/signal-bloom.mp3" }]
  });
</script>
