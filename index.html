Mixtape Player

Embeddable audio player for polished mixes, broadcasts, and story-led releases.

A single-file web component with waveform, drag and drop, remote sources, and UI presets. Designed to feel editorial rather than generic, with enough flexibility to sit inside almost any site.

Single-file runtime Local + remote audio Minimal, compact, full

Playlist Input

Drop a set straight onto the player.

Drag MP3, WAV, OGG, or M4A files onto the player to build a playlist on the fly.

Remote Sources

Point it at a hosted track.

Paste a direct audio URL. If the source allows CORS, the player draws the real waveform automatically.

Embedding

Use the full player or start from a lighter preset.

The same runtime can ship as a full listening surface, a compact embed, or a minimal single-track player.

Single Snippet

<script
  src="https://your-domain.com/dist/mixtape-player.min.js"
  data-mixtape-widget
  data-variant="full"
  data-config='{"title":"Northbound Signals","artist":"Mira Vale","tracks":[{"title":"Signal Bloom","src":"/audio/signal-bloom.mp3"},{"title":"Night Ferry","src":"https://example.com/audio/night-ferry.ogg"}]}'
></script>

Classic Mount

<script src="dist/mixtape-player.min.js"></script>
<mixtape-player id="player"></mixtape-player>
<script>
  const player = document.querySelector("#player");
  player.load({
    title: "Northbound Signals",
    artist: "Mira Vale",
    tracks: [{ title: "Signal Bloom", src: "/audio/signal-bloom.mp3" }]
  });
</script>
