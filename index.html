Standalone Web Component

Embeddable web player with a single snippet and direct drag and drop

A vanilla JavaScript player with no framework and no build step. Use it with local files dropped straight onto the player or with remote URLs, then embed it anywhere with a single snippet.

Drag and Drop on the Player

Drag MP3, WAV, OGG, or M4A files directly onto the widget and they will be added to the playlist immediately.

Add a Remote URL

Paste a link to a remote audio file. If the server allows CORS, the player will render the real waveform; otherwise it falls back gracefully.

Single Snippet

<script
  src="https://tuo-dominio.it/mixtape-player.js"
  data-mixtape-widget
  data-variant="full"
  data-config='{"title":"My Playlist","artist":"Various Artists","tracks":[{"title":"Intro","src":"/audio/intro.mp3"},{"title":"Remote Track","src":"https://example.com/music/track.ogg"}]}'
></script>

Classic Mode

<script src="mixtape-player.js"></script>
<mixtape-player id="player"></mixtape-player>
<script>
  const player = document.querySelector("#player");
  player.load({
    title: "My Playlist",
    artist: "Various Artists",
    tracks: [{ title: "Intro", src: "/audio/intro.mp3" }]
  });
</script>

Minimal Variant

<script
  src="https://tuo-dominio.it/mixtape-player.js"
  data-mixtape-widget
  data-variant="minimal"
  data-config='{"title":"Single Track","artist":"Demo","tracks":[{"title":"Intro","src":"/audio/intro.mp3"}]}'
></script>

Compact Variant with Override

<script
  src="https://tuo-dominio.it/mixtape-player.js"
  data-mixtape-widget
  data-variant="compact"
  data-show-volume="false"
  data-config='{"title":"Compact Player","artist":"Demo","tracks":[{"title":"Intro","src":"/audio/intro.mp3"}]}'
></script>
